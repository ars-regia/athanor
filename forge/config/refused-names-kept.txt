# Sentences of an approved specification that name a component ADR-0141 refuses and that no correct
# revision removes (scripts/verify.py refused-names, #1460): a sentence that only records a
# retirement, a replacement or a refusal, or states a fact about a third party's application or
# package. One entry per line, four fields separated by a tab: DOCUMENT, the NAME or the
# comma-separated names the sentence holds (as forge/config/refused-names.txt reports them), the
# TEXT, which is the whole sentence exactly as it stands in the document (a paragraph, a list item
# or a table row is cut into sentences first), and the REASON, written for this sentence.
# The text is taken out of the document before the names are counted, so a sentence added next to
# it is still a hit. A sentence that says Athanor uses, ships, starts, writes or reads the name, or
# that it stays or is kept until something happens, belongs to forge/config/refused-names-allow.txt
# under #1355 with an expiry; a sentence kept here has none. An entry fails when its text no
# longer appears in a normative section, so a changed sentence must be read again. The list only
# shrinks: a pull request adds no entry. Only the sections Context, Sources, Spikes, Open doubts
# (or questions) and Risks are history; every other section, and the text before the first
# heading, is read.
