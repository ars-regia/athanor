# Crates a specification under docs/architecture names as a dependency although no Cargo.toml
# of its components uses them (scripts/verify.py spec-deps, #1289, #1510), one entry per line:
# `DOCUMENT COMPONENT CRATE REASON`. COMPONENT is a path of docs/architecture/components.toml
# that the document owns and that holds a manifest, or `repo` for a document that owns none, whose
# crates are matched against every manifest of the repository. The forms the check reads are those of
# SPEC_DEPS_FORMS; a sentence that says the crate is planned, or absent, names no dependency.
# The list only shrinks: an entry that no longer applies leaves it, and against --known-red-base a pull
# request adds none, except an entry whose finding the base already had under this matcher: the document,
# components.toml and every manifest of the document's scope (its components' manifests, or all when it
# owns none, the root's, and those its sentences cite) are byte-identical at the base. A stricter matcher
# can list what it finds that way; an edit of a text, a manifest or components.toml cannot. The check prints
# each entry it accepts as new.
