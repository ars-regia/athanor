## Base

Athanor 0.9 ships on Fedora 43 ([ADR-0115](../decisions/0115-zero-nine-in-one-week.md) item 3).
The rebase to a newer Fedora ships as release 0.10.

## Absent from this release

- **Screenshot and screen share.** Release 0.9 ships without them; they return with the first
  release after steps 4 and 5 of `doc_portal.md` are ready
  ([ADR-0129](../decisions/0129-capture-leaves-0-9.md) item 3).

## Known limits

- **#600:** the shell's surfaces are doubled after an output is disabled and enabled in software.
  Milestone 1.0.
- **#604:** on the NVIDIA desktop the GPU falls off the bus on resume from suspend or on an
  output unplug. Milestone After 1.0.
