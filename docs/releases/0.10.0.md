# Athanor 0.10.0 "base"

TO BE COMPLETED BEFORE THE v0.10.0 TAG.

Release 0.10 moves Athanor's base from Fedora 43 to Fedora 45 (ADR-0123), before Fedora 43
reaches its end of life on 2026-12-02 (ADR-0135).

## Before you update

- **Remote login is off after the update.** Fedora 45's desktop preset disables `sshd`, and the
  update follows it on a machine where `sshd` was enabled only by the image's default
  configuration (ADR-0142). To turn it on again, from a console:
  `sudo systemctl enable --now sshd.service`. On a network in the `public` zone, also open the
  port with `firewall-cmd --permanent --zone=public --add-service=ssh` and
  `firewall-cmd --reload`, or put the connection in the `home` zone (ADR-0119 point 3).
- **A machine that must stay reachable over `ssh` across the update** adds this link before it:
  `sudo systemctl add-wants graphical.target sshd.service`.
- **The QEMU guest agent is off after the update.** On a machine that runs in a QEMU or KVM
  virtual machine, `qemu-guest-agent` no longer starts when the hypervisor offers its channel.
  Once turned on, it answers only an allow-list, with no commands, files, passwords or SSH keys
  (ADR-0144). To turn it on: `sudo systemctl enable --now qemu-guest-agent.service`. On
  hardware nothing changes: the agent never ran there.

## Base

Athanor 0.10 ships on Fedora 45: `quay.io/fedora-ostree-desktops/base-atomic:45`.
