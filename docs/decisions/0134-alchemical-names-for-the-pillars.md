# 0134. The pillars of Athanor take alchemical names; every other package keeps a descriptive one

**Accepted** by the maintainer on 2026-11-04, in conversation.

## Context

[ADR-0121](0121-own-compositor-and-toolkit.md) makes the compositor and the toolkit Athanor's
own, and the own stack is now the default session. The project already has two proper names that
a user or a developer recognises as products: Azoth, the kernel, and Calmo, the visual identity.
The components that sit beside them carry the descriptive names `athanor-compositor`,
`athanor-toolkit` and `athanor-update`, which describe a function and do not say that the
component is Athanor's own work. The naming rule of
[repository-layout.md](../operations/repository-layout.md) gives every crate and package an
`athanor-*` name and lists its exceptions; it has no rule for a component that is a product.

The name Athanor is the alchemists' hermetic furnace and vessel, in which the work is done. Azoth
is the alchemists' mercury, the spirit that moves everything.

## Decision

The components Athanor owns that a user or a developer recognises as products, called here
pillars, take alchemical proper names. Every other package keeps a descriptive
`athanor-<function>` name.

| Pillar | Name | Meaning | Today | After |
| --- | --- | --- | --- | --- |
| Kernel | **Azoth** | Mercury, the spirit that moves everything | Azoth | unchanged |
| Compositor | **Sulphur** | Sulphur, fire and light, what makes visible | `athanor-compositor`, `athanor-compositor-client`, and the session script `athanor-compositor-session` | `athanor-sulphur`, `athanor-sulphur-client`, `athanor-sulphur-session` |
| Toolkit | **Sal** | Salt, body and form, what is fixed | `athanor-toolkit` | `athanor-sal` |
| Updates and chain of trust | **Sigillum** | The sigillum Hermetis that seals the vessel: the immutable, signed image is the sealed vessel | `athanor-update`, `athanor-trust-state`, the image and kernel signing | named Sigillum in documents and interface; crate and package renames settled in the Sigillum pull request |
| Desktop shell | **Opus** | The Work, done in the vessel | `athanor-bar`, `athanor-dock`, `athanor-launcher`, `athanor-greeter-ui`, the control center, `athanor-shelld` | the parts keep their names; Opus names the whole in documents and the interface |
| Build system | **Forge** | | Forge | unchanged |
| Visual identity | **Calmo** | | Calmo | unchanged |

1. **Azoth, Sulphur and Sal are Paracelsus's tria prima**: mercury the spirit, sulphur the soul
   and salt the body. Sigillum
   seals the vessel they compose, and Opus is the work done in it.
2. **Opus is a name for the whole, not a package.** Its parts keep their descriptive names.
3. **What is not renamed.** The Wayland and D-Bus identifiers already published, the
   `athanor_*_v1` protocols and the `os.athanor.*` names, because a client built against them
   would break; and the names of third-party software and its specifications, `cosmic-comp`,
   `polkit` and `greenboot-rs`.
4. **How the renames land.**
   1. This record first.
   2. Then one mechanical rename pull request per pillar, started after the pull requests open
      when this record was accepted are merged, so that no open branch is rebased across a rename.
   3. A renamed RPM carries `Obsoletes:` and `Provides:` of its old name, so that an installed
      system updates to it.
   4. The rename of Sigillum touches signing paths, which `AGENTS.md` lists under "Stop and ask
      before editing". That pull request is asked before its code is written.
5. **ADR-0126 decision 4 is amended.** It kept the crate's name `athanor-toolkit` and left the
   name of the toolkit to the maintainer at the split; the maintainer chooses Sal now, so the crate
   becomes `athanor-sal` with the pull request of its pillar. The rest of ADR-0126 stands.

## Consequences

- `docs/operations/repository-layout.md`, "Naming", states the rule and the names. Crates and
  packages stay `athanor-*` under their present names until the pull request of their pillar
  lands.
- Each rename pull request is mechanical and changes nothing else. It touches:
  - the crate name and directory, the workspace `Cargo.toml` members and the `Cargo.lock`
    entries, regenerated by the tool;
  - for a component shipped as an RPM (the compositor and the updates), the spec directory and
    file under `forge/specs/`, the RPM name, `Obsoletes:` and `Provides:` of the old name, and its
    entry in `forge/config/packages.json`, which uses short names such as `compositor`; the crates
    built into another package (`athanor-toolkit`, `athanor-compositor-client`,
    `athanor-trust-state`) have no RPM of their own;
  - the installed binaries, the systemd units, presets, tmpfiles and sysusers files, and the
    paths under `/usr/libexec` and `/usr/share` that carry the name;
  - the entry in `docs/architecture/components.toml`;
  - the specifications, the decision records' links, the guides, the scripts, the workflows, the
    tests, the fuzz corpus directories and the checks of `scripts/verify.py` that name it;
  - a specification's approved text that names the old identifier, through a revision approved
    with that pull request, as ADR-0074 requires.
- What does not change: the published protocol and bus names of decision 3, the behaviour of any
  component, the text of accepted decision records, which keep the names they were written with,
  and `cosmic-comp`, `polkit` and `greenboot-rs`.
- A user's installed system updates through the `Obsoletes:` and `Provides:` of the renamed RPM.
- The pull request of Sigillum is asked before it is written, as `AGENTS.md` requires for
  signing, keys and Secure Boot.
- The rename inventory of each pillar is prepared before its pull request and is not part of
  this record.

## Alternatives considered

- **A proper name for every package.** Rejected: a proper name for a helper tells the reader
  nothing about what the package does, and the descriptive `athanor-<function>` name stays the
  better locator for a part.
- **Names only in documents.** Rejected: the name in a document and a different name in the
  crate, the RPM, the unit and the binary leaves every reader a table to consult, which is the
  state this record removes.
- **Other pairs offered for the compositor and the toolkit.** Coagula and Solve (the two
  movements of the Work), Pelican and Alembic (alchemical vessels), and Rebis and Lapis (the
  double matter and the stone). Not taken: the maintainer chose Sulphur and Sal, which with
  Azoth are the tria prima.
