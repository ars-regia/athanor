# Road to 1.0: Implementation Plan

**Status:** agreed with the maintainer on 2026-11-21, together with the scope decisions in section 2. This plan orders work. It approves no specification text: code waits for its approved text, under ADR-0074.

**Goal:** release 1.0 as fast as correctness allows. The priority order is Sulphur, then Sal, then Settings. The exit criterion is ADR-0141's "everything own": `forge/config/own-allow.txt` is empty (#1292), and the image ships no COSMIC code, no GTK and no Nautilus.

**Basis:** a weighted census of the 1.0 milestone and of the work no issue tracks, made at `origin/iso-v0` 29309029c. Weights are S=1, M=3, L=8, XL=20. Most sizes are estimates, not measurements.

Two facts were checked at the source, and both change the order the census suggested:

- **Settings does not wait for the file manager.** Settings' requirements on Sal are SL1 to SL9 (`doc_settings.md` section 7). The file manager's are SR1 to SR14 (`doc_own_stack.md` decision 39). They are separate sets.
- **Little of Sulphur's standard-protocol gap is left.** The gap list of 2026-11-11 named touch, drm-lease, alpha modifier, fifo, tearing control, background effect and the Xwayland keyboard grab, and each now appears in Sulphur's source. Colour management does not, and it leaves 1.0 (section 2).

## 2. Scope decisions of 2026-11-21

- **The keyring prompter (SystemPrompter) is in 1.0.** ADR-0141 decision 2 already says so. ADR-0138 and `release-1.0` section 3 place it in 1.1, and #1355 brings them in line. Its code waits for the LP12 cryptography plan to be approved and for spike L9.
- **Colour management and HDR come after 1.0.** Output stays at 8 bits, as decided on 2026-11-11, and colour gets a revision of its own after 1.0.
- **The milestone is tidied**, as the maintainer confirmed after reading the list:
  - #538 is closed as complete for 0.9, and #1402 tracks the OS19 acceptance of 1.0;
  - #1364 to #1369 stay open: they are the spike S1 items that never ran, to be run in later sittings (decision of 2026-11-20);
  - #446 moves to After 1.0, since its deadline is 2027-06-14;
  - #1122 is closed, done in #1232.

## 3. Wave 0: unblock

1. **Drain the open pull requests.** #1398 goes first: it records the approval of the texts that Files, Settings, the file chooser, the lock and the Sulphur protocols are built on. After it come #1352, #1387, #1390, #1394, the Orchestrator alert, and the code of the lock's confinement.
2. **Write the missing or stale specification texts, as one batch for one approval session.** They are documents only, so they fall outside the limit of ten open pull requests (ADR-0139):

   - a `doc_session` revision in which a failed session falls back to the recovery console, not to cosmic-comp (ADR-0141 decision 6);
   - `doc_software` SW15 to SW17, and the icon theme that replaces `cosmic-icon-theme`;
   - `release-1.0` revision 10 and the rest of #1355;
   - the 1.0 boot chain (#1345);
   - the UT2 key hierarchy (signing area);
   - the LP12 cryptography plan, for the prompter.

4. #1237: Orca 51 on Fedora 45.
5. The greeter UI port, last, because it handles the password (decision 34; stop and ask before editing).
6. Removing the gtk features of the shared crates, which empties the crate half of `own-allow.txt`.

### Lane 3: Settings, from the merge of #1398

1. `athanor-settings-core`: the window, the page registry, and SE1 to SE8. Spike SE-S1 measures the cold start and settles SE-Q1, whether Settings stays resident.
2. The pages, one pull request each and several at a time, ordered so that each retires COSMIC as early as it can:
   - Desktop, Appearance and Wallpaper, which retire the layout chooser and Calmo's COSMIC overlay;
   - Keyboard and Mouse;
   - Displays (SL7, output management);

3. Retire `cosmic-settings` and `cosmic-settings-daemon`.

## 5. Lanes that start when their dependencies land

**Lane 4: Files and the file chooser.**
- The steps: `athanor-files-view` (FM1 to FM21), then the chooser backend in the portal's backend process, then Nautilus leaves `athanor-desktop-ui` and Bazaar replaces `cosmic-store`.
- At about 47 weight units this is the longest chain. When it contends with Settings for Sal work or a build slot, Settings goes first.

**Lane 5: lock, polkit and the prompter.** Each step except USBGuard is in a stop-and-ask area: authentication, polkit, or cryptography.
1. Enable `athanor-lock` and `athanor-unlockd.socket`, and retire `cosmic-greeter` as the locker.
2. The USBGuard policy service.
3. `athanor-polkit-agent`, which retires `cosmic-osd`.
4. The SystemPrompter, after LP12 and spike L9.

**Lane 6: security and system, in the background.** This lane takes every build slot the first three lanes leave free. Several of its items gate the release:
- #1344, #1347 (the confined class, which ADR-0143 places in 1.0), #1345, #1354, #1066;
- #1350, #1351, #1357, #1348, #1363, #128;

## 7. Throughput and estimate

**What sets the pace is capacity, not the critical path.** The limits are:
- one heavy build at a time on each host, the desktop and the laptop;
- ten open pull requests (ADR-0135);
- a merge card and an approval for each merge.

Lanes 1 to 3 are therefore kept busy at all times, and lane 6 fills the free slots.

**Measured pace:** 231 merges in the 12 days to 2026-11-21. Milestone issues closed at about 20 weight units a week. That count runs low, because the ports already done (the bar, the launcher, the control center and the OSD) had no issues.

**Estimate:** 9 to 12 weeks, so between late January and mid-February 2027. Approving the wave 0 texts quickly is what shortens it most.
